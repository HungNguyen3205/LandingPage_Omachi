# Omachi — Từ gói mì đến tô ngon

Landing page tĩnh với sáu cảnh minh họa chuyển theo thao tác cuộn, từ mở gói đến tô mì hoàn chỉnh. Ảnh WebP được lưu trong repo. Trang hỗ trợ trình duyệt trên điện thoại và thiết lập giảm chuyển động.

## Chạy ở máy local

```sh
python3 -m http.server 8000
```

Mở http://localhost:8000. Có thể đưa thư mục gốc lên dịch vụ hosting tĩnh mà không cần bước build.

## Thay hình

Thay `assets/01.webp` đến `assets/06.webp` theo thứ tự gói mì, xé gói, thả mì, rót nước, thêm gia vị và tô hoàn chỉnh.
